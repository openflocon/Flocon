# Internal docs

Documentation for Flocon maintainers and contributors: how Flocon works inside and how the project is run.
It is not published. The public user docs live in `docs/`, built with MkDocs and published at https://openflocon.github.io/Flocon/.

| Folder | Content |
|---|---|
| [`protocol/`](protocol/README.md) | The mobile ⇄ desktop protocol: connection, message format and each plugin's methods and payloads |
| [`roadmap/`](roadmap/) | Release roadmaps, one file per version (e.g. [`2.0.0.md`](roadmap/2.0.0.md)) |
| [`plans/`](plans/) | Design proposals for features not implemented yet, one file per topic (e.g. [`database-sqldelight.md`](plans/database-sqldelight.md)) |

Add a new folder here for any other maintainer-facing topic (architecture, release process, design notes…), and list it in this table.
